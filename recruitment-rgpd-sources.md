# Sources RGPD — Recrutement international

## CNIL — Recrutement et données personnelles dans les TPE/PME

Source : https://www.cnil.fr/fr/recrutement-et-donnees-personnelles-dans-les-tpepme-cinq-questions-incontournables-se-poser

Consultée le 17 août 2026.

Constats utiles pour Hippocampus Consulting :

- Les données collectées doivent être pertinentes et strictement nécessaires à l’évaluation des compétences et qualifications professionnelles.
- Il est interdit de demander des informations sans lien direct avec l’emploi, notamment numéro de sécurité sociale, coordonnées bancaires, informations sur la famille ou projet d’enfants.
- Les finalités doivent être déterminées, explicites et légitimes ; une candidathèque ne doit pas reposer sur une fausse offre d’emploi.
- L’accès aux CV doit être limité aux personnes chargées du recrutement.
- L’information du candidat doit couvrir le responsable du traitement, les finalités, la base légale, le caractère obligatoire ou facultatif des champs, les destinataires, la durée de conservation et les droits.
- Une conservation dans un vivier après candidature non retenue est possible sous réserve d’en informer le candidat et, en principe, de ne pas dépasser deux ans à compter du dernier contact.
- Le traitement doit être documenté dans le registre des activités de traitement ; une AIPD peut être nécessaire selon les risques.

## CNIL — Le guide du recrutement

Source : https://www.cnil.fr/fr/le-guide-du-recrutement

Consultée le 17 août 2026.

Le guide distingue 19 fiches portant notamment sur les finalités, la base légale, les données collectables, les habilitations, les droits, l’information, la conservation, la documentation, les outils de tri automatisé, les candidats étrangers et les données sensibles.

Points critiques pour cette fonctionnalité :

- Ne pas collecter de données de santé, d’origine ethnique, de convictions religieuses ou d’autres données sensibles dans le formulaire général.
- Ne pas mettre en place de tri algorithmique ou de décision automatisée sans analyse juridique, transparence et garanties appropriées.
- La collecte de données relatives à la nationalité peut être justifiée dans certains cas, mais ne doit pas devenir un critère discriminatoire ; le formulaire doit privilégier les pays d’opportunité et les autorisations professionnelles pertinentes.
- Les données d’un candidat doivent être protégées par des habilitations et des mesures de sécurité appropriées.

Ces sources orientent la structure du formulaire, la notice de confidentialité, les durées de conservation, le contrôle d’accès et le registre de traitement. Elles ne remplacent pas une validation juridique adaptée au rôle exact d’Hippocampus Consulting dans chaque pays.
